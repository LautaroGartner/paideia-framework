# Security Policy

Paideia favors:

- small trusted runtime surfaces
- explicit runtime behavior
- inspectable generated output
- minimal dependencies
- secure defaults

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected vulnerabilities. Report them privately first.

Use GitHub Security Advisories or direct maintainer contact when reporting a vulnerability.

Include:

- affected version
- reproduction steps
- expected impact
- proof of concept if available

## Supported Versions

Current supported line:

- v1.3.x
