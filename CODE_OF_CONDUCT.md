# Code of Conduct

Paideia should be a thoughtful, respectful place to discuss generated systems, runtime design, security, and developer tools.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially in technical disagreement.
- Keep feedback focused on ideas, code, documentation, and project direction.
- Help make the project easier to understand and safer to use.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Demeaning language or exclusionary behavior.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.

## Enforcement

Maintainers may moderate, edit, or remove comments, issues, pull requests, or other contributions that do not align with this code of conduct.

Serious or repeated violations may result in temporary or permanent exclusion from project spaces.
